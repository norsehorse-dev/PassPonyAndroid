3.0: post-quantum keys for passage stores, with a guided move for a store you already have. Keep a store in a folder that Syncthing or another app syncs, no git needed. A pass store can use keys kept in PGPony or OpenKeychain. pass stores now run on the same OpenPGP engine as iPhone and desktop, so entries written by current GnuPG open. Adding an entry under a taken name asks before replacing it. No longer supported: pass keys on the secp256k1 curve.
